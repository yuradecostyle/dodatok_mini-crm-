# Mini CRM 2.0

Особистий застосунок для одного власника: фінанси, планер, проєкти, ліди. Працює на телефоні як PWA:
встановлюється на головний екран і надсилає push-нагадування.

**Адреса:** https://1.decostyle.com.ua (вхід лише для власника).

## Можливості

| Розділ | Що вміє |
|---|---|
| **Сьогодні** | Результат місяця, витрати на виробництво й дім, борг постачальникам, очікувані оплати від клієнтів, справи на сьогодні зі швидким додаванням, найближчі нагадування, ліди для контакту, неоплачена комуналка, проєкти в роботі |
| **Фінанси → Операції** | Доходи й витрати за трьома напрямами: 🏭 виробництво, 🏠 дім, 👤 особисте. Є категорії, контрагенти й привʼязка до проєкту |
| **Фінанси → Звіт** | Зведений звіт за місяць або рік: витрати за напрямами й категоріями, виробництво по проєктах, доходи, комунальні, розрахунки, графік по місяцях. Інвестиції показано окремо, вони не входять у результат. **Деталізація:** натисніть на напрям, категорію, доходи чи комунальну послугу, щоб побачити кожну операцію (на що, коли, кому) з фільтром за категоріями й підсумком по контрагентах |
| **Фінанси → Комуналка** | Послуги за місяцями, показники лічильників з автоматичним розрахунком суми, термін оплати з нагадуванням. Оплачена послуга автоматично стає витратою «Дім → Комунальні». Є копіювання послуг із попереднього місяця |
| **Фінанси → Розрахунки** | Рахунки постачальників і очікувані оплати від клієнтів, часткові оплати, залишок, нагадування в день терміну |
| **Фінанси → Контрагенти** | Довідник постачальників, клієнтів та інвесторів з пошуком за назвою, телефоном і нотатками. Нові імена з операцій і розрахунків зберігаються автоматично, у формах зʼявляються підказки. Картка контрагента показує, скільки сплачено й отримано, борги, рахунки та всі операції. Перейменування оновлює всі записи |
| **Фінанси → Інвестиції** | Отримані й повернуті кошти, підсумок по кожному інвестору |
| **Планер** | День, тиждень, місяць, «Списки» (справи без дати). Галочки виконання, пріоритети, повторення, нагадування, перенесення невиконаних справ, швидке додавання списком (кожен рядок — окрема справа) |
| **Проєкти** | Проєкти з кольором та іконкою, список справ (зокрема додавання списком), прогрес, дедлайн, фінанси проєкту, привʼязка до ліда |
| **Ліди** | Людина, запит, сума, етап воронки, наступний контакт з нагадуванням. **Рекламні канали (джерела)** — редагований список: стартові «Особистий/Робочий Viber», «Особистий/Робочий Telegram» плюс власні (Instagram, Facebook, сайт, OLX, рекомендації…), додаються прямо з форми ліда. Статистика за каналами, кнопки звʼязку, перетворення ліда на проєкт |

## Голос і навігація

- 🎤 **Справи голосом**: кнопка мікрофона в полях швидкого додавання, у формі справи, у «Справах списком» і пункт «Справа голосом» у меню «＋». Розпізнавання українською (Web Speech API; якщо браузер не підтримує — мікрофон на клавіатурі телефону).
- Фраза розбирається автоматично: «завтра о 15:30 подзвонити постачальнику» → справа на завтра, 15:30, з нагадуванням. Розуміє «сьогодні/завтра/післязавтра», дні тижня, «о 9», «о 18 00», «нагадай».
- Кожне вікно має кнопку **←** (крок назад, з оновленими даними) і **✕** (закрити все); системна кнопка «Назад» на Android теж повертає на крок.
- Інтерфейс зафіксовано під телефон: без масштабування, зуму при введенні та горизонтальних зсувів.

## Нагадування

- Сервер щохвилини перевіряє, чи настав час нагадування (`php artisan reminders:send` у контейнері `minicrm-scheduler`), і надсилає Web Push на всі пристрої, де ввімкнено сповіщення (⚙️ → «Увімкнути на цьому пристрої»).
- Нагадування надходять про справи (у вибраний час), ліди (о 09:00 у день наступного контакту), оплати постачальникам і від клієнтів, а також про комуналку (о 09:00 у день терміну).
- На Android у сповіщенні є кнопки «✓ Виконано» та «+15 хв».
- **Звук.** Коли додаток відкритий, грає мелодія, вибрана в налаштуваннях. Для системних сповіщень на Android звук налаштовують так: Налаштування → Програми → Mini CRM → Сповіщення → Звук. На iPhone вебзастосунки використовують системний звук, і змінити його окремо не можна.
- **iPhone.** Push працює лише у встановленому додатку: Safari → Поділитися → «На екран „Додому“». Потрібна iOS 16.4 або новіша.

## Технології

- Laravel 13 (PHP 8.3), SQLite, сесійна автентифікація для одного власника.
- Фронтенд: односторінковий застосунок на чистому JS без збірки (`public/app/app.js`, `public/app/app.css`), service worker `public/sw.js`.
- Push: `minishlink/web-push`, VAPID-ключі генеруються автоматично й зберігаються в базі.
- API: `GET /api/state`, `POST/PUT/DELETE /api/{leads|projects|tasks|settlements|utilities|transactions}`, `POST /api/tasks/bulk`, `/api/push/*`, `GET /api/export`.

## Сервер (Hostinger VPS, Docker Manager)

- Проєкт **`minicrm`** містить два контейнери: `minicrm` (FrankenPHP, порт 80) і `minicrm-scheduler` (`schedule:work`).
- Дані лежать у томі `minicrm_data` (`/data`): база `database.sqlite`, ключ `app_key`, сесії й журнали. Оновлення їх не стирають.
- Домен проксує спільний Caddy з проєкту `marta_school` (мережа `marta_school_default` → `minicrm:80`).
- У Environment проєкту задаються `OWNER_EMAIL` та `OWNER_PASSWORD`. Вони потрібні лише для першого створення власника, далі пароль змінюється в ⚙️.
- **Оновлення:** коміт і пуш, потім створити Docker-проєкт `minicrm` з URL
  `https://raw.githubusercontent.com/yuradecostyle/dodatok_mini-crm-/<SHA-коміту>/deploy/compose.yaml`.
  Hostinger клонує репозиторій і збирає образ з `deploy/Dockerfile`.

## Локальний запуск

```sh
composer install
cp .env.example .env && php artisan key:generate
touch database/database.sqlite && php artisan migrate
OWNER_EMAIL=me@example.com OWNER_PASSWORD=change-me-123 php artisan owner:ensure
php artisan serve            # застосунок
php artisan schedule:work    # нагадування
```
