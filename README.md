# Mini CRM — мобільний додаток

Особистий помічник на телефоні: фінанси, контроль повідомлень, дошка справ і ліди.
Це PWA (Progressive Web App): він відкривається в браузері, встановлюється на головний екран
Android або iPhone, працює офлайн і не потребує збірки. Дані зберігаються на самому пристрої.

## Можливості

| Розділ | Що вміє |
|---|---|
| 🏠 **Головна** | Загальний баланс, доходи й витрати за місяць, справи на сьогодні з прогресом, повідомлення без відповіді, нові ліди |
| 💰 **Фінанси** | Доходи та витрати за категоріями, перегляд по місяцях, діаграма витрат за категоріями, залишок за місяць |
| 💬 **Повідомлення** | Єдиний список важливих повідомлень з **пошти, Telegram і Viber** (особисті й групові); статуси *Нове / Відповісти / Чекаю відповідь / Оброблено*; нагадування «відповісти до»; кнопка, що відкриває чат у Telegram/Viber або лист; перетворення повідомлення на ліда чи справу; автоматичне завантаження з Telegram-бота |
| ✅ **Справи** | Дошка справ на **день**, **тиждень** (колонки по днях) і **місяць** (календар із прогресом за кожен день). Виконані справи відмічаються галочкою. Є пріоритети, час, повторення, прострочені справи та перенесення невиконаних |
| 🎯 **Ліди** | Фіксація потенційних запитів: імʼя, контакт, запит, **джерело звернення** (Instagram, Facebook, Telegram, Viber, сайт, рекомендація тощо), етап воронки, сума, дата наступного контакту. Є статистика за джерелами, конверсія, пошук, дзвінок або повідомлення в один дотик. Якщо закрити ліда як успішного, сума додається в доходи |

У ⚙️ **Налаштуваннях** можна змінити валюту, підключити Telegram-бота, зробити експорт або імпорт резервної копії (JSON) і завантажити демо-дані.

## Як встановити на телефон

1. Розмістіть файли на будь-якому HTTPS-хостингу, наприклад GitHub Pages: *Settings → Pages → Deploy from branch*.
2. Відкрийте посилання на телефоні:
   - **Android (Chrome):** меню ⋮ → «Додати на головний екран» / «Встановити додаток».
   - **iPhone (Safari):** «Поділитися» → «На екран „Додому“».

Для локальної перевірки на компʼютері виконайте `python3 -m http.server` у папці проєкту й відкрийте `http://localhost:8000`.

## Повідомлення: що працює автоматично

- **Telegram-групи:** створіть бота в `@BotFather`, вимкніть для нього `/setprivacy` і додайте його в потрібні групи. Потім вставте токен у Налаштуваннях. Кнопка «Завантажити нові з Telegram-бота» підтягне повідомлення з цих груп і особисті повідомлення, надіслані боту.
- **Особисті чати Telegram, Viber і пошта** додаються вручну кнопкою «＋». Ці сервіси не дозволяють читати особисте листування без власного сервера: для Viber такого API немає взагалі, а для Gmail потрібна OAuth-авторизація через бекенд.

## Структура

```
index.html     — розмітка та навігація
styles.css     — стилі (світла й темна теми, адаптивність під телефон)
app.js         — уся логіка (localStorage)
sw.js          — service worker для офлайн-роботи
manifest.json  — маніфест PWA
icons/         — іконки
```
